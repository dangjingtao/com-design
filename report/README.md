## Archive policy

Before replacing a published report, preserve an exact dated snapshot first.

Current pre-pipeline archive:

```text

```

The exact historical repository state is preserved on:

```text
archive/design-system-v1-pre-pipeline-2026-08-12
```

Archived reports are reference material only. They never feed future builds and never become a design-system source of truth.

The complete build and archive contract is defined in `design-source/BUILD_PIPELINE.md`.
