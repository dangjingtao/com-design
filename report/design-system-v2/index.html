DESIGN PRINCIPLES

先有层级，再有装饰。

Open Design 提供的是文档产品化的视觉启发；Com Design 自己的语义、层级和约束不让位。

01

Semantic first

颜色、状态、动作与组件都先表达语义，再映射到平台表现。

02

Flat first

优先使用排版、留白、分隔与中性 surface 建立结构，不用卡片和阴影堆层级。

03

Primary is scarce

一个视图或动作组通常只有一个最高优先级动作，Brand 不承担“哪里都要亮”的职责。

04

One source, many consumers

Human Guide、Penpot、AI Contract 与平台 Adapter 都是 downstream consumer，不制造第二真相源。

FOUNDATIONS

同一套语义，允许不同上下文。

当前页面本身也消费这些 semantic tokens；右上角可以切换 Default / Premium Gold 与 Light / Dark。

Color semantics

Brand 用于身份、选择、focus 与关键动作；状态色只承载状态语义。

Typography

中文优先，信息密度高，但不拥挤。

Display → Title → Heading → Body → Caption 保持稳定层级。

Spacing & radius

页面节奏来自 canonical spacing；圆角用于控件与容器，不把所有区块都卡片化。

Platform context

Android / iOS / Web / WeChat Mini Program 共享设计意图；viewport、input、motion、color scheme 独立解析。
