Core

33 个组件属于公司级稳定候选能力。产品可以消费、组合，但不能因为某个业务页面临时改写 Core API。

Pattern

表单、搜索、反馈、导航等跨组件行为属于 Pattern，不应该为了“看起来完整”硬塞成新组件。

Product Extension

活动卡片、行业状态、业务金刚区等保留在产品层。真实跨产品复用出现后，再评估是否进入 Core。
