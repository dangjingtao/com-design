Design System V1 · Design Review

Com Design Mobile

公司级移动端设计系统。当前是 Release Candidate。本报告看三件事：视觉语言是否成立、设计模式是否一致、Stable 前还缺什么。

33 Core Components 2 Core Patterns 4 Orthogonal Axes iOS / Android
当前完成度：33 个 Core Component 已完成规范与机器契约定义；PenPot 正式可复用资产仍需对齐与最终验收。Iconography 是当前 V1 明显缺口之一。
01

品牌性格

不讲抽象价值观，直接讲它应该怎样影响界面。

清晰 Clear

主次关系先于装饰。正文、辅助信息、动作、状态各有固定层级，不靠堆颜色抢注意力。

视觉后果：系统字体、明确字阶、低噪声背景、有限高纯度色。

轻快 Light

高信息密度，但页面不沉。用冷调 Neutral、留白和薄边界保持呼吸感。

视觉后果：Flat-first；普通信息层不靠 Shadow。

高效 Efficient

默认 Compact，让常见业务页面一屏承载更多有效信息，同时不牺牲阅读和点击。

视觉后果：40px 控件、48px 行高基线；Hit Area 独立满足平台要求。

年轻 Young

年轻感来自 Electric Indigo 与局部 Cyan 的节奏，而不是霓虹、渐变、软萌大圆角。

视觉后果：品牌色鲜明但少量使用；Accent 永远不与 Brand 抢主身份。
一句话：冷静但不沉重，年轻但不轻浮，紧凑但不拥挤。

03

设计模式 Design Patterns

组件解决“一个控件怎么做”；Pattern 解决“一组控件怎样一起工作”。

01

信息组织

Section-before-Card。先用标题、间距、Divider 建层级；只有真正独立的实体才进入 Card。禁止 Card 套 Card 作为默认结构。

02

表单

Label → Control → Helper/Error 保持稳定。Field-level error 优先，不把字段错误升级成 Toast。Read-only 与 Disabled 必须可区分。

03

导航

Bottom Navigation 管顶层目的地；Tabs 管同层内容视图；Segmented Control 管局部模式。三者不因“长得像”而互相替代。

04

搜索

Search 不是普通 Input。保留 Query、Clear 和已有结果；Loading 不应让用户失去清空能力；No Results 只属于当前查询上下文。

05

反馈层级

Field / Helper → Inline Alert → Banner → Toast / Snackbar → Dialog。越往后打断成本越高，不能因为“重要”就直接弹窗。

06

Overlay

同一时刻只允许一个 Blocking Modal。Menu 先关闭，再打开 Dialog / Sheet；Dialog 不叠 Dialog，Sheet 不叠 Sheet。

07

Loading / Empty / Error

结构已知用 Skeleton；未知等待用 Loading；没有内容用 Empty；请求失败用 Error/Recovery。后台刷新优先保留旧内容。

08

Progress

Progress 表示可计算进度；Stepper 表示待完成的有限步骤；Timeline 表示已经发生的事件历史。三个角色严格区分。

09

Status Composition

Status 是语义组合，不是“彩色胶囊”。文字 / Icon / Tag / Dot / Alert 可以组合，但颜色永远不能是唯一信号。

04

组件范围

这 33 个组件已经做了规范定义。当前未完成的是 PenPot 正式资产对齐与最终视觉验收，而不是“33 个名字先占坑”。

05

不是业务原型，只看这套语言组合后是否仍然一致。

07

RC 遗留

这些是 Stable 前真正要处理的，不包装。

Stable 前

Iconography 补齐

确定默认图标源、尺寸、stroke、语义映射、Custom Icon 规则，并进入正式规范 / PenPot / 实现消费路径。建议 Lucide。

Stable 前

PenPot 对齐

Formal Spec、Light/Dark、Compact/Comfortable specimen、Reusable Component Asset 与 V1 Manifest 对齐并完成导出审计。

Stable 前

独立二审与真机抽查

独立 reviewer 验证 33 + 2、关键引用、iOS / Android typography / controls 与真实平台行为。

历史债

semantic.light namespace

Dark 当前通过 Overlay 覆盖历史逻辑 namespace。V1 可兼容保留，后续版本再评估迁移收益。

后续

Adaptive / Pointer

平板、折叠屏、宽屏和 Pointer 平台尚不是 V1 承诺范围，后续根据真实产品需求扩展。

后续

新增 Core Component

由真实跨产品复用拉动，不为了让组件数量看起来更完整而扩张。

当前判断：设计语言主体已经形成，但 Iconography + PenPot 正式资产 + 独立二审尚未闭环，因此仍应保持 1.0.0-rc.1。
