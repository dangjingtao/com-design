DESIGN PHILOSOPHY

设计理念

只讲真正影响设计决策的原则。原则必须能在组件和交互里被验证，而不是停留在口号。

01

Semantic First

语义优先

先定义动作、状态和信息职责，再决定颜色与视觉表现。同一种语义在不同平台仍然保持一致。

操作成功 结果已经保存
02

Primary is scarce

主要动作是稀缺资源

一个视图或动作组通常只有一个最高优先级动作。可用不等于都要变成 Primary。

主要操作 次要操作 文字操作
03

Flat First

扁平优先

先用排版、留白、分隔和中性表面建立层级，只有真正需要悬浮与覆盖时才使用 elevation。

04

One Source, Many Consumers

一次定义，多处消费

Human Guide、Penpot、AI Contract 和四端 Adapter 都消费同一套 canonical source，不制造第二真相源。

HPAI4P

VISUAL FOUNDATION

视觉基础

展示“怎么用”，而不是把 token 表整页倒出来。每个基础项都服务于层级、可读性和跨端一致性。

色彩

Semantic color

品牌色用于身份、选择、focus 与关键动作；状态色只表达真实状态。

字体

Type scale
Aa 中文优先Display · Title · Body · Caption

高信息密度不等于拥挤。字号层级少而稳定，文本本身承担主要结构职责。

间距

Spacing

使用离散 spacing scale 建立节奏，避免“差不多”的手写间距不断扩散。

圆角

Radius

圆角是层级和容器职责的一部分，不是默认装饰。控件、容器、overlay 使用明确语义。

图标

Icon language
⌂⌕♡⚙

简洁、清晰、统一的线性图标。图标帮助识别，不替代文字语义。

INTERACTION PRINCIPLES

交互原则

把层级、反馈、状态与恢复路径展示成真实片段。规则应该能在产品界面里被直接看懂。

01

层级与重点

通过动作层级引导注意力，不让多个 Primary 同时竞争。

提交申请确认信息后提交
确认提交稍后处理
02

反馈机制

反馈紧贴动作与影响范围，成功、警告和错误不只依赖颜色。

✓操作成功已完成你的操作
03

状态设计

默认、Pressed、Loading、Disabled 都是明确状态，不用视觉猜测。

默认状态按下状态禁用状态
04

表单行为

输入、提示和错误靠近字段；局部错误不升级成整页 Result State。

请输入手机号请填写正确的手机号
05

结果状态

结果说明发生了什么，并给出真实下一步，而不是只给一个“确定”。

✓提交成功资料已进入审核查看进度
06

加载与危险操作

Loading 保持尺寸稳定；Destructive 是语义，不替代层级。

加载中… 删除记录
