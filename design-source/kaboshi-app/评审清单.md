# 评审清单 — 卡博士诗得丽 App

> 本文件由评审线程使用。生产线程每完成一批（8-10 屏）并 push 后，评审线程逐项核查，产出问题清单交回生产线程修改。
> 评审对象：Penpot「卡博士」文件中的画板，对照 Mockplus 原型与共享库 `com-design-v1`。

## 评审前置

- [ ] 生产线程已 push 并更新 `工作台账.md`（状态=🟩已完成待审、填了负责线程、备注、新增组件、commit）
- [ ] 知道本批包含哪些画板名（模块/编号）
- [ ] MCP 已 Connect here 到「卡博士」文件，能读到共享库 `com-design-v1`
- [ ] 逐屏 `export_shape` 导出 PNG，并打开 Mockplus 原型对应页面截图并排对照

## A. 结构与内容（对照原型）

- [ ] 页面区块顺序、分栏、导航/内容/Tab 位置与原型一致
- [ ] 所有文案、数字、标签、按钮文字与原型一致（不错字、不遗漏）
- [ ] 列表项/卡片数量、空状态、错误状态、弹窗齐全
- [ ] 该有的图标、头像、缩略图位置正确
- [ ] 「暂时不做」的页面没有误做

## B. Token 与组件合规（重点）

- [ ] 颜色全部来自共享库 `com-design-v1` 的 color token，**没有写死 hex**
- [ ] 文字全部应用库 typography，没有手动设字号/字重
- [ ] 间距/圆角/阴影使用 token 或库规范值，没有随意数值
- [ ] 已有库组件（Button/Card/ListItem/TopAppBar/Dialog/BottomSheet/Checkbox/Avatar/Badge/Tabs/Search 等）用的是**组件实例**，不是自己重画的
- [ ] 自建业务组件引用了 token，且已登记到台账"新增业务组件"
- [ ] 切到 Dark 主题（如适用）颜色不崩；至少不出现写死的浅色值

## C. 布局与视觉质量

- [ ] 画板尺寸 390×844，命名规范，按模块分区排布
- [ ] 对齐：元素左/右/居中对齐一致，间距成体系，无肉眼可见错位
- [ ] 无溢出、裁切、层级遮挡、重叠
- [ ] Flex/auto 布局撑开正确，无塌陷、无多余空隙
- [ ] 文字无重影/色散（嵌套 flex 导致的小数像素问题，必要时锁整数坐标）
- [ ] 圆角、阴影、边框样式统一
- [ ] 状态栏/导航栏/底部 Tab 高度与位置全站一致

## D. 素材图

- [ ] 原型里的低质 3D 图/乱图已替换为风格统一的靠谱图
- [ ] 图片比例正确、不虚化、不变形
- [ ] 替换记录在台账备注
- [ ] 没有遗留占位灰块（除非约定为占位）

## E. 交互

- [ ] 原型里能点的元素都连了交互（navigate-to / overlay / 返回）
- [ ] 跳转目标画板正确
- [ ] 弹窗用 Overlay，能打开也能关闭
- [ ] 按钮状态（default/pressed/disabled）用变体表达
- [ ] **没有原型里不存在的自创跳转**

## F. 交付与标注

- [ ] 内容画板干净（没有手机壳/装饰元素混入，手机壳只在演示画板）
- [ ] 画板 `clipContent` 正常，命名清晰
- [ ] 进检查/Code 模式抽查 2-3 个元素，尺寸(pt/dp)、颜色、字号可读
- [ ] 需要切图的图标/位图导出设置正确

## G. 批次完整性

- [ ] 本批 8-10 屏全部完成，没有半成品空框
- [ ] 台账状态、备注、新增组件、commit 已更新
- [ ] 遇到的待确认问题已列出（如商城 H5 处理方式）

## 评审输出格式

```
## 批次 X 评审结果（commit xxx）
结论：通过 / 有条件通过 / 打回
- 阻断问题（必须改）：
- 建议问题（可选）：
- 待确认：
- 做得好的地方：
```
