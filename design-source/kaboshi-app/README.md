# 卡博士诗得丽 App — 设计协作文档

本目录是“卡博士诗得丽”移动端 App 的 Penpot 设计任务协作文件，供跨线程/跨会话接力使用。

## 文档说明

- penpot-工作方法.md：工作方法与底线（交付立场、视觉闭环、对照核查、跨线程交接协议）。
- 项目约定.md：本项目的具体事实（文件/库、token 用法、范围顺序、交互与设备框、线程职责、踩坑记录）。
- 工作台账.md：72 屏逐屏进度表、批次划分、新增组件登记、待确认问题。生产线程每批做完必须更新。
- 评审清单.md：评审线程用，逐项核查标准与输出格式。阻断问题未修复不进入下一批。

技术层面的 Penpot MCP API 操作手册：../PENPOT_MCP_PLAYBOOK.md。

## 线程分工

- 生产线程：每批 8-10 屏，直接用 com-design-v1 组件与 token，走视觉闭环，做完更新台账并 push。
- 评审线程：按 评审清单.md 核查每批产出，出问题清单，不通过不进入下一批。

## 新生产线程开场

见 项目约定.md 第 11 节。
