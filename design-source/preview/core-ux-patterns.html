Core UX Patterns

6 个多组件 UX 组合示例。它们不增加 33 个 Core Component 的数量；示例只展示层级、状态、回流和上下文关系，机器契约以 specs/core-patterns.json 为准。

01 · STATUS COMPOSITION

状态组合

状态不是一块颜色，而是可读状态 + 必要解释 + 下一步。

待审核

资料已提交

预计 1–2 个工作日完成审核

审核完成前可以继续浏览内容，但暂不能提交正式申请。

04 · STATE TO ACTION

状态到动作

先判断权威状态，再决定用户现在唯一最重要的动作。

05 · INTENT CONTINUITY

意图连续与回流

登录或外部流程只是暂时中断，不应该让用户丢掉原本要做的事。

原任务提交申请
→
暂时中断登录 / 授权
结果映射更新原状态
→
回到任务继续提交
